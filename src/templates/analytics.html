What these values mean

Behavior detections
Raw behavior boxes emitted per frame. The saved history CSV contains assigned tracker records, which can differ.
Tracker records
One tracker ID's assigned behavior in a processed frame. Cached observations are included where the source analysis includes them.
Tracker ID
A video-scoped tracking label. It is not a unique real-world student identity.
Video span
Maximum history-row timestamp produced by the existing session-statistics function; it is not a wall-clock processing duration.
